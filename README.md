# csv2json

**Convertit un CSV (virgule ou point-virgule, format Excel FR) en JSON propre.**

Zéro dépendance · Node.js 18+ · Windows, macOS, Linux.

## Utiliser tout de suite (sans rien installer)

```bash
npx github:zrk-lol/csv2json-fr clients.csv > clients.json
```

## Installer la commande `csv2json`

```bash
npm install -g github:zrk-lol/csv2json-fr
csv2json clients.csv > clients.json
```
